# Archiplayer -> Tolaria memory

Tolaria's Archiplayer project memory is at:

`F:\Documents\Tolaria\projects\archiplayer\`

If you, the acting agent, successfully push this repository to a Git remote, update that Tolaria
project memory immediately after the push succeeds. Record factual repository state only:

- the pushed commit and branch;
- verification performed and its result;
- any local modifications or untracked files that remain after the push;
- decisions established by the pushed work; and
- concrete next steps.

Never describe local, uncommitted, untracked, or otherwise unpushed work as pushed or remote
state. Do not update Tolaria merely because another person or process pushed, unless the current
task explicitly asks you to reconcile that external push.

This is an agent instruction, not a Git hook. Do nothing under this rule when no push succeeds.
